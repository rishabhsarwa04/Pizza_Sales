# Pizza_Sales
The Pizza Sales Analysis Project aims to analyze the performance of a pizza store using structured SQL queries and visualize business insights through Power BI dashboards.  The project’s primary goal is to extract meaningful insights about sales trends, customer behavior, product performance to help stakeholders make data-driven business decisions.
### **Objectives:**

- Clean and prepare raw sales data for accurate analysis.
- Derive key business metrics (KPIs) such as **Total Revenue**, **Average Order Value**, and **Total Pizzas Sold**.
- Identify sales trends over **days and hours** to determine peak ordering times.
- Analyze the performance of different **pizza categories and sizes**.
- Highlight **best and worst-selling pizzas** to optimize menu offerings.
- Create a visually interactive dashboard in **Power BI** for real-time monitoring and insights.
